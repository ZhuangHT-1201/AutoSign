# 隐私与安全

## 收集的数据

课迹没有自建后端，不主动收集、上传或出售个人数据。

设备本地可能保存：

- 校园服务 Cookie 与会话状态
- 显示名称和脱敏后的账号标识
- 最近一次成功同步的课表快照
- 连接方式偏好

## 密码

统一认证页面由学校提供。用户在该页面输入账号与密码，课迹不读取表单内容，也不保存密码。

## 网络请求

请求直接发生在设备与学校系统之间。桌面端使用 Chromium 原生会话，Android 端使用系统 Cookie 与原生 HTTP 连接。

## 删除数据

在“设置与账户”中可以：

- 清除离线课表缓存
- 退出登录并清除校园 Cookie

卸载应用时，操作系统通常会一并清理应用私有存储。

## 日志与问题反馈

课迹不会自动上传日志。提交 Issue 前，请移除 Cookie、票据、学号、姓名、课程表和任何真实响应正文。
